# Pre-generated art — `the-word` gift beat

`beat-0.png` (256×256) is **pre-generated, not yet wired** into `SCENE_ASSETS`
(`src/art/sceneAssets.ts`). It depicts Pip (fox kit) receiving the lantern —
the Word as light — from the Keeper (luminous heron) at dawn. Catalogued here so
the upcoming `the-word` phase can consume it; wire it when that scene's beats are
authored. Generated via the PixelLab REST `generate-image-pixflux` endpoint.

> Note: pixflux follows the subject best when the **subject leads** the prompt and
> the style codex is condensed and trails it. Putting the full style block first

> issue on prompt ordering. Minor `v5` glyph artifact bottom-right.
